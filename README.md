# 念念不忘

> 凌晨三点四十七分，我的电脑自己亮了。
>
> 桌面上多了一个我从没建过的文件，里面只有一句话——"你回来了。"
>
> 是谁？
>
> 为什么监控里的那些事，我完全不记得？
>
> ——这台电脑里，好像有什么东西，一直在等我。

## 游戏简介

《念念不忘》是一款以**虚拟电脑**为核心载体的网页解谜游戏。玩家将扮演女主角许念，在凌晨三点四十七分打开自己的电脑，却发现电脑中出现了许多自己完全不记得创建过的文件、搜索记录和聊天内容。

所有互动都在同一台虚拟电脑内完成——文件管理器、浏览器、微信、公寓监控、音频播放器……每个应用都高度还原真实软件的界面和操作。玩家需要在不同应用之间来回切换，通过摩斯密码、栅栏密码等谜题，逐步揭开三年前一场事件的真相，以及主角失去的记忆。

- **游戏类型**：网页解谜游戏（ARG风格 · 虚拟电脑探索）
- **解谜风格**：本格解谜 + 情感叙事
- **预计时长**：60-90分钟（一周目）
- **操作方式**：鼠标点击 + 键盘输入

## 如何运行

1. 下载全部文件到同一个文件夹
2. 双击 `index.html` 用浏览器打开（推荐 Chrome / Edge）
3. 点击屏幕任意位置开始游戏
4. 戴上耳机体验更佳（含旁白音频和背景音乐）

> **注意**：游戏包含音频和视频，需要保持所有资源文件在同一目录下。请勿单独移动 HTML 文件。

## 游戏提示

- 游戏没有固定的点击顺序，可以自由探索
- 部分剧情有前置条件，需要先完成某些操作才能触发
- 如果卡住了，试试在不同应用之间切换，线索可能藏在意想不到的地方
- 注意桌面右下角的便签、文件的修改日期、浏览器的历史记录
- 游戏通关后有二周目彩蛋，24小时内再次打开可体验

## 技术说明

- 纯 HTML + CSS + JavaScript 单文件实现，无需服务器
- 音频使用 Web Audio API 合成（哼歌.mp3的摩斯密码）
- 视频和图片资源为本地文件，需保持目录结构完整
- 游戏进度通过 localStorage 保存（二周目状态）
- 兼容 Chrome 90+、Edge 90+、Firefox 88+
